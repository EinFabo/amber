# Amber: roadmap after the 2026-11-06 plans

Fabi's plan of 2026-11-06, as decided. Progress is tracked in [`docs/OPEN.md`](../OPEN.md) ("Roadmap").

## Context

Fabi reviewed the four plans in `docs/plans/2026-11-06-*.md` (missing features, cleanup prompt,
bubble quick menu, bubble behaviour) and added a list of his own points. Goal: a simple app for the
standard user (little or nothing to set up) and full control for people who want to customise -
plus fixing what hurts today (cleanup that translates or changes meaning, a bubble that sits
mid-screen in landscape and follows the keyboard badly, wrong commas before "und").

## Findings that shape the plan

- Settings are written with all fields, so new defaults (auto-pause, languages, app styles, engine)
  reach new installs only; existing users keep their values. Schema steps only where data moves.
- Several servers need no id rename: "groq", "openai", "self-hosted" are unique already; the work
  is the 5 preset-by-id lookups (`EngineDetailScreen.kt:126`, `MainActivity.kt:380/473`,
  `ServerProviders.addressFixed`, `ChoiceSteps.kt:56`). New servers get opaque ids `server-xxxx`.
- `GermanCommas` never adds a comma before "und"; the wrong ones come from the engine or the
  cleanup. A removal rule in the normalizer (runs after the cleanup in `deliver()`) catches both.
- UI text is hardcoded English in ~20 Compose files; `:core` builds sentences (`SettingsSummaries`,
  `SttFailure.userMessage`, validator, presets). German needs string resources + typed values first.
- Dark-only theme; ~250 direct `AmberPalette` uses -> keep the name, back it by a CompositionLocal.

## Roadmap (one commit series per phase, each with tests and a device check)

**P0 - License and rules (S).** Apache-2.0 `LICENSE` + `NOTICE` (whisper.cpp MIT, sherpa-onnx
Apache-2.0, onnxruntime MIT, tinfoil-go and model licenses to check) + "Licenses" row in Settings.
CLAUDE.md: app text English + German resources; code/comments/commits/logs/diagnostics English.
Write `docs/AMBER-PC-REVIEW-PROMPT.md` (auth, key in path vs header, bind/LAN, TLS, upload caps,
decoder safety, model-id path traversal, logging, rate limits, prompt injection, deps) for Fabi to
run in amberPC. Update OPEN.md (stale items; later list).

**P1 - Cleanup quality (L).** `docs/plans/2026-11-06-cleanup-prompt.md` steps 1-5 in `ChatCleanup.kt`:
hard rules first with the language named (`LanguageGuess` in `:core`), self-correction rule, styles
that say what may change, user text fenced; `plausible` -> verdict with reason (negation, numbers,
language, preamble, line breaks); word test stays on with own instruction (0.4). Global own addition
`cleanupInstruction` + read-only "View system prompt". Duden rule in `GermanCommas`: drop a wrong
", und/oder/sowie" (keep after an inserted/sub clause). Eval set + runner under `tools/cleanup-eval/`
(needs Fabi's keys).

**P2 - Bubble edge-dock + quick menu (L, schema 11).** Place first, then show; clear of system bars
and cutout; snap to left/right edge with fling; own height above the keyboard; landscape keeps the
side. Long-press = menu (hold-to-talk removed from `BubbleController.TouchHandler` and
`DictationController.start(holdToTalk)`); 4 slots in the inward half. `:core`: `BubbleDock`,
`QuickMenuGeometry`, `BubbleGesture` state machine, `QuickActions`. Slots: Idle - insert again, copy
last, cleanup here on/off, hide here; Listening - cancel, send without cleanup, start over;
Transcribing - cancel, keep as recognized.

**P3 - Simpler surface (M, schema 12).** Hide voice commands (nav row, page, double tap, "everywhere"
toggle, diagnostics filter; code behind a flag; accessibility description without commands). Global
"Advanced settings" switch via a `:core` `SettingsLayout` table (simple: recognition phone/server,
cleanup on/off, bubble, app styles; rest advanced). `autoStopOnSilence = false`; onboarding
recording step removed.

**P4 - UI language (L).** Move text to `strings.xml` + `values-de` + `locales_config`; `:core`
returns typed values mapped to text in `ui/Texts.kt`; glossary `docs/GLOSSARY.md` for plain words
(Fabi approves; e.g. Engine -> Spracherkennung / Speech recognition). Diagnostics stay English.

**P5 - One "Server" entry + app-side security (L, schema 13).** One addable "Server" (several
allowed), auto-labelled by host/catalog; Tinfoil separate. Fixes: key bound to host, `Redact.url`
for logs/traces, refuse http to public addresses (resolve names), response size caps, model-id
checks, no redirects with a key; header auth if the amberPC review allows it.

**P6 - Languages everywhere + recognition per app (M/L).** `:core` `LanguageList` (default = phone
languages; first code for single-language engines; Parakeet "detects itself"; per engine/profile
editable); one chip component. `AppProfile.appEngine` + `EngineRouting` like `CleanupRouting`;
replace every `activeEngine` use in `DictationController`.

**P7 - Onboarding quick/deep/skip + first-run defaults (M).** Quick: welcome, accessibility,
microphone, done - engine from `EngineAdvice.recommend` (Android until the download is ready, Wi-Fi
gate). `KnownApps` catalog (~30 apps) -> `AppProfiles.defaultsFor(installed)`.

**P8 - Light mode (M).** `AmberColors` light/dark via CompositionLocal, `ui.theme` System/Light/
Dark, system bars, `values-night`, screenshots in both themes.

**Later (OPEN.md):** Tinfoil mail + referral, subscription with "can't see your data", Gboard mic
key, QR scan, custom voice commands / phone remote-control mode, bubble idle fade, rename, Play
readiness, Amber PC adopting the new prompt.
